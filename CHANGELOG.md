# Changelog

All notable changes to shell-tunnel will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [1.4.1] - 2026-11-26

### Changed
- The two connect commands print as bare lines with no `$` prefix, so a triple-click copies exactly the command. The docs page demo matches.

## [1.4.0] - 2026-11-26

### Added
- Dial-home retries every 5 seconds until the listener answers, instead of exiting on the first failed attempt; a wrong baked password also retries (Ctrl+C to stop). New late-listener regression test.
- Callbacks are numbered (`Session 1: …`) and print two paste-ready commands: a ControlMaster line (`ssh -fNM -S /tmp/shell-tunnel-<port>.sock …` with `UserKnownHostsFile=/dev/null`, `StrictHostKeyChecking=no`, `ServerAliveInterval=60`, `ServerAliveCountMax=10` and `ExitOnForwardFailure=yes`) and the connect line over that socket, so SFTP and forwards share one authenticated connection and per-run host keys never touch `~/.ssh/known_hosts`. The `build.sh` handler teaches the same two lines.
- `-V` / `--version` prints `shell-tunnel vX.Y.Z` and exits 0.
- Dial-home sends `keepalive@openssh.com` every 15 seconds, so NAT and stateful-firewall idle timeouts don't eat parked callbacks.
- The PTY shell falls back to `/bin/sh` when the default `/bin/bash` is missing on the target (explicit `-s`/`RS_SHELL` paths are honoured verbatim). New unix-only test, 18 tests in total.

### Changed
- Renamed from Undertow to shell-tunnel, following the RFS naming rule (`thing-it-does`, lowercase, hyphens). The repository, CLI binary, build outputs, release assets and docs page all take the new name; the upstream fork note and the original copyright headers are unchanged.
- `[ok]` and `[!]` lines (listener up, callback landed, denied requests, failed logins, retry notices) now print by default; `-v` only gates the `[i]` detail lines. Quiet NOCLI builds stay silent.

### Fixed
- Interactive password entry no longer spins in an infinite redial loop when stdin cannot be read; the error is returned.
- `-h` exits 0 and a flag parse error exits 2, per the CLI contract (0 ok, 1 runtime, 2 usage); previously help exited 1.
- The SFTP server is closed on every exit path, not just a clean EOF.
- `-d`/`DAEMONIZE` detached children no longer inherit the launching session's stdio handles (nc or evil-winrm would stay held open); stdio now points at the null device on both unix and Windows.

## [1.3.0] - 2026-11-26

### Added
- Project branding and documentation
- Security policy
- Contributing guidelines
- GitHub issue and PR templates
- GitHub Pages site
- CI workflow (gofmt, go vet, go test, cross-compile build matrix for Linux, Windows and macOS)
- Release workflow (tagged releases with 6 cross-compiled assets and SHA256SUMS.txt)
- Repository guardrails (AGENTS.md)
- RFS Cyclorama Dawn branding: README cover and social preview generated by `rfs-brand/tools/make-cover.py`, and a rebuilt handbook-style docs page
- Bracketed status tokens (`[ok]`, `[!]`, `[x]`, `[i]`) with the Cyclorama Dawn terminal palette in the binary and in `build.sh`, honouring `NO_COLOR`, `TERM=dumb` and non-TTY output with a 16-colour fallback
- In-process test suite (16 tests): parameter parsing, certificate generation, password and public key authentication over the wire, exec with exit status, PTY shell, SFTP round trip, direct-tcpip and remote forwarding, the rs-info channel, and the full dial-home reverse flow

### Changed
- Updated all dependencies, including `golang.org/x/crypto` from the 2021 pin to v0.59.0 (clears known SSH vulnerabilities) and `gliderlabs/ssh` to v0.3.8
- Minimum Go version is now 1.26
- README: honest binary size (about 6.5 MB stripped; the "under 1.5 MB" claim predates the current Go runtime), removed the dead link to the never-released Neap, and documented the fork-of-Ferdinor lineage

### Fixed
- `ssh.Server` is now passed by pointer; the newer `gliderlabs/ssh` server struct contains a `sync.WaitGroup` and must not be copied
- Exec sessions no longer lose the exit status: the stdin copier could close the session before `s.Exit` ran, and clients reported "remote command exited without exit status" (upstream race, caught by the new tests)
- Line endings pinned to LF for Go sources, shell scripts and the Makefile via `.gitattributes`

### Removed
- UPX compression support; packed binaries invite heuristic AV detections and saved little against the current Go runtime
- The template-generated placeholder docs page

## [1.0.0] - Initial Release

### Added
- Reverse shell mode with auto-callback
- Bind shell mode with listener
- Full PTY support (Linux via creack/pty, Windows via ConPTY)
- Built-in SFTP subsystem for file transfer
- Local, remote, and dynamic (SOCKS) port forwarding
- TLS wrapping with ALPN negotiation and SNI spoofing
- Single static binary under 1.5MB
- Cross-compilation for Linux and Windows (x86/x64)
- Handler script auto-generation
- Password and ED25519 public key authentication
- UPX compression support
- Catppuccin Mocha themed build output
- Runtime CLI flags (listen mode, port, shell, verbose)
- IPv6 support
